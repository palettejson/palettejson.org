## Project Overview

This is the documentation website for PaletteJSON - a portable JSON container format for color palettes. The site is built with Docusaurus 3.8.1 and serves as the primary documentation hub at https://palettejson.org.

## Architecture

### Documentation Structure
- **`docs/`** - Core documentation in Markdown format
  - `docs/spec/` - PaletteJSON schema specification broken down by object type:
    - `root.md` - Root object structure
    - `palette.md` - Palette object properties
    - `color.md` - Color object definitions
    - `accessibility.md`, `color-spaces.md`, etc. - Specialized topics
  - `intro.md`, `quick-start.md`, `examples.md` - User-facing guides
- **`src/`** - Docusaurus customizations (minimal usage)
- **`static/`** - Static assets (images, favicons, schema files)

### Configuration
- **`docusaurus.config.ts`** - Main Docusaurus configuration
  - Sets up Algolia search integration
  - Configures i18n (currently US English only, prepared for expansion)
  - Links to external schema repository
- **`sidebars.ts`** - Uses autogenerated sidebar from docs folder structure
- **`tsconfig.json`** - TypeScript configuration for Docusaurus

## Development Commands

## Content Guidelines

### Documentation Standards
- All documentation follows established patterns from existing spec pages
- Use Docusaurus features: tabs, admonitions (:::tip, :::warning, :::note)
- JSON examples must be valid and properly formatted
- Cross-reference related concepts using established page structure
- Maintain consistency with existing terminology and style

### Schema Documentation Pattern
The project uses a specialized agent (`json-schema-documenter`) for maintaining schema documentation. Each spec page follows this structure:
1. Overview explaining purpose and context
2. Properties with types, descriptions, constraints
3. Practical examples with valid JSON
4. Cross-references to related concepts

### Internationalization Preparation
- Default locale is US English (`en-US`)
- Content should be written in clear, translatable English
- Avoid cultural references or idioms
- Future localization will be handled by specialized agents
